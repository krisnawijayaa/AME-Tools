About

AME Toolbox

Version –

Digital toolbox untuk Aircraft Maintenance Engineer — converter, calculator, dan reference, 100% offline, tanpa akun dan tanpa server.

Project

AME Toolbox dibangun sebagai Progressive Web App ringan: HTML, CSS, dan JavaScript murni, tanpa framework maupun backend. Seluruh data (Favorites, History, Settings, Notes) tersimpan lokal di perangkat kamu lewat localStorage — tidak pernah dikirim ke server mana pun.

Privacy Policy

AME Toolbox tidak mengumpulkan, mengirim, atau membagikan data pribadi apa pun. Tidak ada akun, tidak ada tracking, tidak ada iklan. Semua Favorites, History, dan Settings hanya tersimpan di localStorage browser kamu, dan bisa dihapus kapan saja lewat Settings → Reset, atau dengan menghapus data situs dari browser.
